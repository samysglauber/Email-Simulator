# SESI Mail — Simulador de E-mail

Simulador de caixa de e-mail para uso em aula de informática. Roda inteiramente no navegador, sem servidor ou banco de dados — os dados existem só durante a sessão de cada aluno.

## Como acessar

Depois de publicado no GitHub Pages, basta abrir o link do site — não precisa instalar nada.

## Funcionalidades

- Caixa de entrada com e-mails de exemplo (professores, secretaria, colegas)
- Ler, responder, arquivar, marcar como importante e excluir mensagens
- Anexar arquivos de exemplo ou arquivos reais do computador
- Respostas automáticas simuladas ao enviar e-mails

## Publicado com GitHub Pages

Este repositório usa GitHub Pages para servir o `index.html` diretamente como site.
